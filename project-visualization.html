📋 Visão Geral

O Deal Hunt é uma plataforma completa desenvolvida com Laravel 11 e Livewire 3 que permite aos usuários descobrirem as melhores promoções de jogos digitais.

🎯 Objetivo Principal

  • Agregação de ofertas de múltiplas lojas
  • Notificações em tempo real
  • Sistema de wishlist inteligente
  • Conversão de moedas automática

✨ Diferenciais

  • Tradução automática PT-BR
  • Autenticação 2FA (Google Authenticator)
  • Design responsivo moderno
  • Painel administrativo completo

🗂️ Modelos Principais

Game

Modelo principal que representa um jogo e suas ofertas.

Campos principais:

  • title, image, store, store_name
  • normal_price, sale_price, discount_percent
  • deal_ends_at, description, external_id
  • is_active, is_free_permanently

Relacionamentos:

  • belongsToMany Category
  • belongsToMany User (wishlist)
  • hasMany GameTranslation

User

Modelo de usuário com autenticação 2FA e preferências.

Funcionalidades:

  • Autenticação via Fortify
  • 2FA com Google Authenticator
  • Gerenciamento de wishlist
  • Preferências de moeda e tema

GameTranslation

Armazena traduções de descrições de jogos.

Campos:

  • game_id, field_name
  • original_text, translated_text
  • translation_method, language

Notification

Sistema de notificações em tempo real.

Tipos:

  • GameDiscountNotification
  • GameOnSaleNotification
  • Notificações customizadas

Category

Categorias de jogos (Ação, RPG, Estratégia, etc.)

Outros Modelos

  • AdminLog - Logs administrativos
  • AppMetric - Métricas do sistema
  • LoginHistory - Histórico de logins
  • TrustedDevice - Dispositivos confiáveis
